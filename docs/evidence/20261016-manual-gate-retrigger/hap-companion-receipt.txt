  - strong: Description
  - text: ":"
  - text: HAP 打包工具创建 ZIP entry 时使用当前时间。相同输入在不同时间打包后，ZIP entry 时间戳不同，从而导致生成的 HAP 字节内容和 SHA-256 不一致。
- heading "修改内容" [level=3]
- list:
  - listitem: 为 HAP ZIP entry 定义统一的固定时间；
  - listitem: 对普通文件和 JSON entry 设置固定时间；
  - listitem: 对并行压缩的 native library entry 设置固定时间；
  - listitem: 对 STORED entry 和空目录 entry 设置固定时间；
  - listitem: 通过统一方法设置 ZIP entry 时间，避免不同打包路径遗漏。
- heading "修复边界" [level=3]
- paragraph: 本修改解决：
- paragraph:
  - code: 相同输入 → ZIP entry 时间固定 → HAP 字节和 SHA-256 可重复
- paragraph: 不解决：
- list:
  - listitem: 上游 native library 重复 dirty；
  - code: compile_app.py
  - text: 声明输出问题；
  - listitem: 两个 HAP compile_app Action 是否完全退出第二轮构建。
