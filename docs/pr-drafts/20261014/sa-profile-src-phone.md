### 原因（目的、解决的问题等）
SA 元数据顺序不固定，生成脚本在 JSON 内容未变化时也会覆盖文件；原来的 JSON 比较方式还会将对象键顺序变化判为内容变化，导致输出时间戳更新，触发下游重复构建。

### 描述（做了什么，变更了什么）
对 SA 元数据按 label 排序，源 SA 信息和安装信息仅在内容变化时写入。公共 JSON 比较改为比较解析后的内容，忽略对象键顺序差异。

### 测试用例（新增、改动、可能影响的功能）
预期内容不变时保留原文件和时间戳，避免继续触发下游构建；内容变化时正常更新，输出文件被删除后能够重新生成。
