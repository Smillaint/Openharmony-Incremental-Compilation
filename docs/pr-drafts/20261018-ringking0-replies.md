## build #6982：单文件路径

对应评论 `194419266`：路径是否对比。

> 单参数 `rebase_path` 会把 `src_idl` 转成系统绝对路径，再次转换不会改变路径。让单文件输入与 `sources` 多文件输入保持一致，避免后续脚本按工具目录解析相对路径。

## build #6982：IDL 读取异常
