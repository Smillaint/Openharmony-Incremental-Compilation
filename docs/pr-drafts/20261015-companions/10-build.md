### 原因（目的、解决的问题等）
loader 先删除 components.json 再写回，相同内容也会更新时间戳，内容变化检查无法生效；公共 JSON 比较还受字典键顺序影响。

### 描述（做了什么，变更了什么）
取消写回前的删除，使用 check_changes 比较后写入；公共 JSON 判断改为比较解析后的内容。

### 测试用例（新增、改动、可能影响的功能）
预期组件清单未变化时保留文件及时间戳，实际组件变化时正常更新，缺失的输出可由写入工具重新生成。
