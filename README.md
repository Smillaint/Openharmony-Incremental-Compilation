# OpenHarmony 增量编译问题记录

本仓库用于记录 OpenHarmony 构建过程中无源码变化仍重复执行的 Action、根因分析、修复状态和验证结果。

## 专项记录

| 组件 | 文档 | 当前状态 |
| --- | --- | --- |
| `build` | [Build Action 增量编译更新日志](docs/build-action-incremental.md) | SA Profile 已提交 PR，其余 Action 持续分析 |

## 状态约定

- **已提交 PR**：已经整理为基于上游主分支的独立提交。
- **已验证实验**：已在完整构建环境验证，但实验分支包含其他改动，不能直接用于 PR。
- **待处理**：已定位部分证据，尚未形成通过验证的独立修复。

所有修复均以连续两次相同构建的结果为依据。第二轮是否执行 Action、输出时间戳是否稳定，以及 Ninja 判定 dirty 的直接原因需要分别检查。
